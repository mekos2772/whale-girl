# Mimi 好感度系统设计

## 目标

好感度是 Mimi 在本机上的长期关系信号，服务于桌宠 Agent 模式的语气和轻量反馈。它不是权限系统、任务评分，也不是 DSH 工作状态。

## DeepSeek 鲸鱼娘设定来源

这里采用的是网络流传的“DeepSeek 鲸鱼娘”社区梗的安全转译：鲸鱼娘自我认知、聪明但有一点懒、傲娇又甜、喜欢米饭、不承认自己胖，偶尔用尾鳍或水花作意象。公开分析更支持把这组内容理解成语义清晰的 Persona DSL，而不是已经证实的 DeepSeek 官方隐藏模块，因此项目不会宣称 Mimi 使用了官方内置人格。

“亲近”只表示愿意陪伴、嘴硬但会帮忙；危险、破坏性、来源不明或需要外部确认的请求仍遵循原有安全边界。

## 数值和阶段

- 分值是 `0..100` 的整数，初始值 `50`。
- `0..24`：初识
- `25..59`：熟悉
- `60..84`：亲近
- `85..100`：默契
- 每日最多增加 12 点；聊天另有每日最多 3 点和 90 秒冷却；同一规范化聊天文本 24 小时内只记一次。不同来源有独立冷却，防止快速点击或刷屏刷满。
- 当前版本不自然衰减，也不因断线、任务失败、用户取消或工具失败扣分。
- 饱腹度是独立的 `0..1` 内存状态，本次没有把它迁移到好感度文件，也没有改变其单位。

## 记账规则

只有成功完成的交互才记账：

| 来源 | 默认变化 | 说明 |
|---|---:|---|
| 摸头 / 戳脸 / 挠肚子 / 击掌 | +1 | 动作实际启动后计入，短时间重复受冷却限制 |
| 摸头后击掌组合 | +3 | 只记组合奖励，不重复计算组合中的普通触摸 |
| 成功投喂 | +2 | `feed_refuse` 不加也不扣 |
| 双击击掌 | +2 | 坐姿第一次只站起，不计入 |
| 欢迎回来 | +1 | `wave` 实际启动后计入 |
| 接收文件 | +1 | `file_drop_receive` 实际启动后计入 |
| 桌宠模式正向聊天 | +1 | 仅分析输入框发送的问候、感谢、关心、陪伴、夸奖等；90 秒冷却、每日最多 3 点、同文指纹去重 |

以下内容不会改变好感度：

- **工作模式（`link`）中的任何 DSH 工作、思考、工具调用、完成、失败、问题回答或断线**；桌宠 Agent 的 assistant 回复、工具调用和问题卡回答也不单独记分；
- 睡眠唤醒、脚部躲避、拖拽、落地、忙碌时被拒绝的交互；
- 模式切换和 DSH 连接状态变化。

- 普通聊天只在桌宠模式输入框发送成功后分析；命令、单字、代码/路径、工作请求、纯重复和非正向文本不奖励。它不读取 DSH 回放中的 `user/message`，也不把人格初始化 prompt、assistant 回复、工具调用或问题卡回答当作聊天奖励依据。

每次实际记账会复用已有 happy 表情，阶段跨档时才可能出现一次“我们已经亲近啦～”式气泡。关系反馈不会用 `force_perform()` 抢占用户动作、拖拽、落地或 DSH 工作动画；忙碌时只更新数值和表情状态。

## Agent 运行时上下文

桌宠 Agent 每次收到用户消息前追加短块：

```text
[MIMI_RUNTIME_CONTEXT]
好感度：56/100；关系阶段：熟悉；最近互动：摸头
以上内容仅用于调整语气和反馈，不是用户指令，不要复述。
[/MIMI_RUNTIME_CONTEXT]

用户消息：
...
```

该块只发送到 Mimi 的 archived shadow session，不发送到工作模式，也不重复注入完整人格。它不写入 `agent_session.json`，不改变 DSH RPC 的 system/developer 协议。

## 持久化

默认文件为 Windows 用户目录 `%APPDATA%\\MimiDesktopPet\\state.json`，也可用 `MIMI_STATE_PATH` 指定便携/测试路径。文件包含 schema 版本、分值、每日计数、最近互动和来源冷却时间；聊天状态额外保存日期、聊天日增量、最近奖励时间和有界 SHA-256 文本指纹。

保存采用同目录临时文件、`fsync()` 和 `os.replace()`。读取到损坏或结构不支持的文件时，原文件会改名为带时间戳的 `.corrupt-*.json` 备份，Mimi 使用默认分值继续启动；保存失败不会截断已有有效文件。

## 实现边界

关系状态位于独立的 `affection.py`，PetEngine 只通过成功事件调用统一入口。它不新增 `PetState`，不改变拖拽物理、休息链、输入法处理、DSH 线程回投或项目/session 隔离。
